**Iskra: alpha 39.**

### Fixes
- Draw & guess: the colours and brush sizes sit beside the board instead of under it, so the whole game fits on screen in a call or full screen without scrolling.

### Get started
- **Windows:** `Iskra-Setup-2.0.0-alpha.39.exe`. **Mac:** the `.dmg`. **Linux:** AppImage, `.deb` or `.rpm`. **Android:** the `.apk`.
- **In the browser:** [app.iskra.foo](https://app.iskra.foo).
- **Your own server:** create one in the desktop app, rent one from the app, or run the `iskra-server` package: `iskra-server my-server`, then open the owner link it prints. The [hosting guide](https://iskra.foo/hosting) has every step.
