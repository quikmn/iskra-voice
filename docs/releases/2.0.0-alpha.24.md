**Iskra: alpha 24.**

### What's new
- **Bug reports in their own window.** "Report a bug" now opens beside the app, so you can keep using Iskra to show the bug. In the desktop app, pick which Iskra window to take a screenshot of, now or in 5 seconds. On phones, **Keep using Iskra** tucks the report into a small chip.
- **See which server you're in.** The server you have open now sits on a tab of the channel list, in your theme's colours.

### Get started
- **Windows:** `Iskra-Setup-2.0.0-alpha.24.exe`. **Mac:** the `.dmg`. **Linux:** AppImage, `.deb` or `.rpm`. **Android:** the `.apk`.
- **In the browser:** [app.iskra.foo](https://app.iskra.foo).
- **Your own server:** create one in the desktop app, rent one from the app, or run the `iskra-server` package: `iskra-server my-server`, then open the owner link it prints. The [hosting guide](https://github.com/quikmn/iskra-voice/blob/main/docs/hosting.md) has every step.
