### What's new

- **Bug reports in their own window.** "Report a bug" now opens beside the app, so you can keep using Iskra to show the bug. In the desktop app, pick which Iskra window to take a screenshot of, now or in 5 seconds. On phones, **Keep using Iskra** tucks the report into a small chip.
- **See which server you're in.** The server you have open now sits on a tab of the channel list, in your theme's colours.
