### What's new

- **Server icon and banner**: owners and admins can give the server a square icon and a wide banner (Server settings → Overview), cropped right in the app. The icon shows in everyone's server list, the header and on invite links before people join; the banner sits above the channel list. Everyone sees changes at once, and the server strips location and other metadata from both.
