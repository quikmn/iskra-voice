**Iskra: alpha 34.**

### What's new
- Bring your own AI: an optional assistant (off by default) that uses a key from the AI provider you choose, or a model on your own computer, to help with Iskra, write bots and organize your server. Your device talks to the provider directly, and every change waits for your OK. The desktop app can also offer its tools to Claude Desktop or Claude Code (MCP).

- Bot gallery: Trivia (weekly scoreboard, no XP), Feeds Plus (keyword filters, Twitch alerts by DM), Server stats (a weekly card, counts only), Jukebox and a Starter template in Node or Python, ready to run or copy. The desktop app runs them for you in My settings → Bots on this PC, and can make the bot invite itself.

### Get started
- **Windows:** `Iskra-Setup-2.0.0-alpha.34.exe`. **Mac:** the `.dmg`. **Linux:** AppImage, `.deb` or `.rpm`. **Android:** the `.apk`.
- **In the browser:** [app.iskra.foo](https://app.iskra.foo).
- **Your own server:** create one in the desktop app, rent one from the app, or run the `iskra-server` package: `iskra-server my-server`, then open the owner link it prints. The [hosting guide](https://iskra.foo/hosting) has every step.

### Good to know
- Report a bug now explains connection problems: how each server is reached (direct or through the peer-to-peer tunnel, and the NAT types), how long connecting took, and voice's network route and quality, all without a single address. A server connection that hangs while connecting now gives up after 30 seconds and tries again.
