**Iskra: alpha 48.**

### Fixes
- Calls: when the microphone you picked in settings no longer exists (phones can give devices new ids), the call uses the default microphone instead of saying "No microphone found".

### Get started
- **Windows:** `Iskra-Setup-2.0.0-alpha.48.exe`. **Mac:** the `.dmg`. **Linux:** AppImage, `.deb` or `.rpm`. **Android:** the `.apk`.
- **In the browser:** [app.iskra.foo](https://app.iskra.foo).
- **Your own server:** create one in the desktop app, rent one from the app, or run the `iskra-server` package: `iskra-server my-server`, then open the owner link it prints. The [hosting guide](https://iskra.foo/hosting) has every step.
