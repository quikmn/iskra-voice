**Iskra: alpha 23.**

### What's new
- **Server icon and banner**: owners and admins can give the server a square icon and a wide banner (Server settings → Overview), cropped right in the app. The icon shows in everyone's server list, the header and on invite links before people join; the banner sits above the channel list. Everyone sees changes at once, and the server strips location and other metadata from both.

### Get started
- **Windows:** `Iskra-Setup-2.0.0-alpha.23.exe`. **Mac:** the `.dmg`. **Linux:** AppImage, `.deb` or `.rpm`. **Android:** the `.apk`.
- **In the browser:** [app.iskra.foo](https://app.iskra.foo).
- **Your own server:** create one in the desktop app, rent one from the app, or run the `iskra-server` package: `iskra-server my-server`, then open the owner link it prints. The [hosting guide](https://github.com/quikmn/iskra-voice/blob/main/docs/hosting.md) has every step.
