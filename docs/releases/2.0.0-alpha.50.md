**Iskra: alpha 50.**

### What's new
- A fresher look: panels, menus and dialogs have fine edges and soft layered shadows, buttons and switches respond when pressed, and corners are a little rounder. Layout and colours stay the same.

### Get started
- **Windows:** `Iskra-Setup-2.0.0-alpha.50.exe`. **Mac:** the `.dmg`. **Linux:** AppImage, `.deb` or `.rpm`. **Android:** the `.apk`.
- **In the browser:** [app.iskra.foo](https://app.iskra.foo).
- **Your own server:** create one in the desktop app, rent one from the app, or run the `iskra-server` package: `iskra-server my-server`, then open the owner link it prints. The [hosting guide](https://iskra.foo/hosting) has every step.
