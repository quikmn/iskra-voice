**Iskra: first alpha.** Voice and text chat for your friend group, on a server you own.

### Get started
- **Windows app:** `Iskra-Setup-2.0.0-alpha.1.exe` (or the portable `.exe`). Click **Create a server** and you're the owner of a server running on your PC, voice included. Invite friends with a link.
- **In the browser:** [app.iskra.foo](https://app.iskra.foo) works on PC and phones.
- **Your own server (home PC or VPS):** the `iskra-server` packages for Windows and Linux. Run `iskra-server my-server` and open the owner link it prints. Built-in automatic HTTPS (Let's Encrypt) for servers on the internet.

### What's in it
- **Accounts without email or passwords:** your account is a key on your device. Save your recovery key to use it on other devices.
- **Text channels:** Markdown, @mentions, replies, reactions, file and image uploads (100 MB by default), link previews.
- **Voice channels:** push-to-talk that works in games, camera and screen share.
- **Direct messages:** end-to-end encrypted, with safety numbers to verify each other.
- **Roles and moderation:** private channels, read-only channels, kick and ban.
- **Your server is a folder:** copy it to back it up or move it.

### Good to know
- This is an alpha: expect rough edges, and tell us what you find.
- The Windows app isn't code-signed yet, so Windows SmartScreen will ask before running it ("More info" → "Run anyway").
- Browsers only connect to servers that use HTTPS, so for a server on your home network friends should use the desktop app.
- The Linux server package hasn't been run on a real Linux machine yet.
