**Iskra: alpha 2.** Voice and text chat for your friend group, on a server you own.

### What's new since alpha 1
- **Start your own server, from anywhere:** the web app now has a *Start your own server* guide: get the Windows app and click *Create a server*, or run the standalone server on a PC or VPS.
- **Settings without a server:** change your name and save your recovery key right from the home screen.
- **A clearer message** when a server can't be reached from a browser because it doesn't use HTTPS.
- **New docs:** [hosting guide](https://github.com/quikmn/iskra-voice/blob/main/docs/hosting.md), [security](https://github.com/quikmn/iskra-voice/blob/main/docs/security.md), [development](https://github.com/quikmn/iskra-voice/blob/main/docs/development.md).

### Get started
- **Windows app:** `Iskra-Setup-2.0.0-alpha.2.exe` (or the portable `.exe`). Click **Create a server** and you're the owner of a server running on your PC, voice included.
- **In the browser:** [app.iskra.foo](https://app.iskra.foo), on PC and phones.
- **Your own server:** the `iskra-server` packages for Windows and Linux. Run `iskra-server my-server` and open the owner link it prints.

### Good to know
- This is an alpha: expect rough edges, and tell us what you find.
- The Windows app and server are code-signed (Open Source Developer Viktor Lundgren). While the app is new, Windows may still ask once before running it.
- Browsers only connect to servers that use HTTPS, so for a server on your home network friends should use the desktop app.
- The Linux server package hasn't been run on a real Linux machine yet.
- Verify downloads with `SHA256SUMS.txt`.
