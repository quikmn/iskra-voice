**Iskra: alpha 14.**

### Fixes
- **The Android app no longer hides under the phone's buttons.** On newer Android phones the menu button, the message box and the bottom of the side panels slipped under the back and home buttons. Everything now stays clear of the status bar, the navigation bar and the keyboard, with gesture or button navigation.

### Get started
- **Windows:** `Iskra-Setup-2.0.0-alpha.14.exe`. **Mac:** the `.dmg`. **Linux:** AppImage, `.deb` or `.rpm`. **Android:** the `.apk`.
- **In the browser:** [app.iskra.foo](https://app.iskra.foo).
- **Your own server:** create one in the desktop app, rent one from the app, or run the `iskra-server` package: `iskra-server my-server`, then open the owner link it prints. The [hosting guide](https://github.com/quikmn/iskra-voice/blob/main/docs/hosting.md) has every step.

### Good to know
- The Android app's version number has one more digit from now on, so a version can be sent to Google Play again; installed copies still update as usual.
