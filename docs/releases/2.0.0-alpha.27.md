**Iskra: alpha 27.**

### What's new
- Pick your roles: admins can mark roles as ones members pick themselves and ask new members about them right after the rules (which platform, which pings); change your picks any time from the server menu or with `/roles`.
- Raid controls: invites that make each joiner wait for a moderator's OK (the queue is under Reports), a switch that pauses every invite, a slowmode for newcomers, and an AutoMod rule that pauses invites by itself when too many people join at once.
- Moderators' tools: select and delete up to 100 messages at once, ban and delete someone's last day or week of messages, warn people, keep private notes and see each member's moderation history, and act on people who already left.
- A picture per server: next to your server nickname you can set a picture that shows instead of your profile picture on that server only.

### Get started
- **Windows:** `Iskra-Setup-2.0.0-alpha.27.exe`. **Mac:** the `.dmg`. **Linux:** AppImage, `.deb` or `.rpm`. **Android:** the `.apk`.
- **In the browser:** [app.iskra.foo](https://app.iskra.foo).
- **Your own server:** create one in the desktop app, rent one from the app, or run the `iskra-server` package: `iskra-server my-server`, then open the owner link it prints. The [hosting guide](https://github.com/quikmn/iskra-voice/blob/main/docs/hosting.md) has every step.
