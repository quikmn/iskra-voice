**Iskra: alpha 45.**

### What's new
- Iskra now speaks Spanish, German, French, Italian, Portuguese (Brazil), Polish and Russian, as well as English and Swedish. It follows your system's language, or pick one in My settings → Language.

### Get started
- **Windows:** `Iskra-Setup-2.0.0-alpha.45.exe`. **Mac:** the `.dmg`. **Linux:** AppImage, `.deb` or `.rpm`. **Android:** the `.apk`.
- **In the browser:** [app.iskra.foo](https://app.iskra.foo).
- **Your own server:** create one in the desktop app, rent one from the app, or run the `iskra-server` package: `iskra-server my-server`, then open the owner link it prints. The [hosting guide](https://iskra.foo/hosting) has every step.
