**Iskra: alpha 49.**

### What's new
- In a call, the mic and speaker buttons have a small arrow that lists your microphones and speakers; picking one switches right away and is remembered. On phones the list is a sheet, and holding the button opens it too.
- Android app: the speaker button's arrow lists where the call can play: Speaker, Phone, and a wired, USB or Bluetooth headset when one is connected.
- A microphone or camera problem in a call now comes with "Choose microphone" (or camera) and "Report a bug".

### Fixes
- When the microphone you picked is no longer there, the call says so and uses the default one, instead of "No microphone found".
- Picking another microphone after the first one failed to start now turns your mic on without rejoining.
- On phones, a microphone error in a call has its own row above the buttons and is shown on the call screen, not only in the channel list.

### Get started
- **Windows:** `Iskra-Setup-2.0.0-alpha.49.exe`. **Mac:** the `.dmg`. **Linux:** AppImage, `.deb` or `.rpm`. **Android:** the `.apk`.
- **In the browser:** [app.iskra.foo](https://app.iskra.foo).
- **Your own server:** create one in the desktop app, rent one from the app, or run the `iskra-server` package: `iskra-server my-server`, then open the owner link it prints. The [hosting guide](https://iskra.foo/hosting) has every step.
