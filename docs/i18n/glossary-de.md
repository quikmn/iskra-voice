# Glossar Deutsch (`de`)

German glossary for Iskra. Same sections and English terms as [`docs/i18n-glossary.md`](../i18n-glossary.md); rules
in [translating.md](../translating.md#glossary).

## Rules for the whole language

- **Address:** informal "du", always lower case (`du`, `dich`, `dir`, `dein`). Never "Sie", never "ihr" for the
  reader.
- **Gender:** neutral wording where it is natural ("Wer …", "alle", "Mitglieder", "Person"). Role names and a few fixed
  nouns use the plain generic form (Besitzer, Moderator, Sprecher); no gender star or colon.
- **Case:** sentence case. Only the first word and nouns (and proper names) are capitalised: "Freunde einladen",
  "Meine Einstellungen". No English Title Case.
- **Buttons and menu items:** infinitive at the end, no article where it reads well: "Server verlassen", "Link kopieren",
  "Kanal erstellen". Running text and hints use full sentences with "du".
- **Quotation marks:** `„…“`. Inner quotes `‚…‘`.
- **Dashes and ranges:** `–` (en dash) with spaces as a pause, without spaces in ranges (`2–4`).
- **Ellipsis:** `…` (U+2026), no space before it at the end of a word ("Lädt…", "Speichern…").
- **Numbers and units:** a space between number and unit ("5 MB", "10 s", "50 %"). Decimal comma in running text.
- **Abbreviations:** "z. B." for "e.g."; "usw." is avoided.
- **Compounds:** German compounds are written together or with a hyphen when a part is an English or product name
  ("Server-Updates", "App-Sperre", "Discord-Import", "LFG-Beitrag"). Prefer a short common word over a long compound.
- **Loanwords kept:** Server, Chat, Bot, Thread, Link, Emoji, Sticker, GIF, Clip, Event, Timeout, Backup, Update, App,
  Passkey, Webhook, Soundboard, Whiteboard, Push-to-Talk, Stream, Feed, Quiz, Team.
- **Not translated:** Iskra, product names (Discord, DigitalOcean, Tailscale, GitHub), `AutoMod`, slash commands, key
  names (`Strg` is NOT used: key names stay as the app shows them, `Ctrl`, `Esc`), file formats.
