For people who like to tinker

Bots you can use and change

No code needed for the basics: eleven small bots (dice, polls, starboard, feeds and more) come with every server; an admin turns them on in Server settings → Bots & webhooks. Want more? The bot gallery has ready-made bots to run or copy: Trivia (a weekly scoreboard, no XP), Feeds Plus (keyword filters, Twitch alerts by DM), Server stats (a weekly card, counts only), Jukebox (your music in voice) and a Starter template with tests, in Node or Python. The desktop app runs them for you (My settings → Bots on this PC), or run one yourself with one command:

git clone https://github.com/quikmn/iskra-voice.git
cd iskra-voice/bots
npm install
npm run trivia

For everyone

Themes

Eleven themes are built in. Make your own in My settings → Appearance → Write your own: a small JSON file with a name and your colours. The app checks that text stays readable. Export it to share it with friends; they import it in the same place.

{
  "meta": {
    "name": "Midnight",
    "scheme": "dark"
  },
  "colors": { "accent": "#ff7a59" }
}

Report a bug, share an idea

The quickest way is in the app: tap your name at the bottom of the channel list and choose Report a bug (on a computer: Ctrl+Shift+B). It adds the details we need, and screenshots if you like. Developers can also open an issue on GitHub.
