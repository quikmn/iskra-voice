# Iskra Mobile PWA — Implementation Plan

## Prerequisite
**Complete the web app first** (`webapp_plan.md`). The mobile PWA builds directly on top
of `iskra_webclient/` — no separate logic, same codebase.

---

## Folder Structure

```
iskra_mobile/
  capacitor.config.json     ← Capacitor config (points to iskra_webclient/)
  android/                  ← generated by Capacitor (git-ignored except config)
  ios/                      ← generated by Capacitor (git-ignored except config)
  package.json
```

`iskra_webclient/` gains these files at the PWA stage:
```
iskra_webclient/
  manifest.json             ← PWA manifest
  service-worker.js         ← app shell cache
  icons/
    icon-192.png
    icon-512.png
    icon-maskable-512.png   ← for adaptive icons on Android
    apple-touch-icon.png    ← 180×180 for iOS
```

## Phase 1 — PWA (Add to Home Screen)

This alone gets 90% of the "app" experience on both platforms with zero store overhead.

### manifest.json

```json
{
  "name": "Iskra",
  "short_name": "Iskra",
  "description": "Self-hosted chat, voice & video",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#0b0b14",
  "theme_color": "#7c3aed",
  "icons": [
    { "src": "/icons/icon-192.png",          "sizes": "192x192", "type": "image/png" },
    { "src": "/icons/icon-512.png",          "sizes": "512x512", "type": "image/png" },
    { "src": "/icons/icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
```

Add to `<head>` in `iskra_webclient/index.html`:
```html
<link rel="manifest" href="/manifest.json">
<meta name="theme-color" content="#7c3aed">
<link rel="apple-touch-icon" href="/icons/apple-touch-icon.png">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
```

### service-worker.js

Cache the app shell so it loads offline (the WS connection still needs network):

```js
const CACHE = 'iskra-v1';
const SHELL = ['/index.html', '/manifest.json', '/icons/icon-192.png'];

self.addEventListener('install', e => e.waitUntil(
    caches.open(CACHE).then(c => c.addAll(SHELL))
));

self.addEventListener('fetch', e => e.respondWith(
    caches.match(e.request).then(r => r || fetch(e.request))
));
```

Register in `index.html` boot sequence:
```js
if (IS_WEB && 'serviceWorker' in navigator)
    navigator.serviceWorker.register('/service-worker.js');
```

### Icon Generation

Source: the Iskra spark logo (SVG or high-res PNG).
Generate all sizes with a tool like `sharp` CLI or `pwa-asset-generator`:
```
npx pwa-asset-generator logo.svg ./icons --background "#0b0b14" --padding "20%"
```

### Installation UX

Android Chrome: browser shows "Add to Home Screen" banner automatically when manifest
+ service worker are present.

iOS Safari: user taps Share → "Add to Home Screen" — no banner. Show a one-time tooltip
on first visit guiding iOS users through this:

```js
if (IS_WEB && /iPhone|iPad/i.test(navigator.userAgent) && !navigator.standalone
    && !localStorage.getItem('pwa-ios-hint-shown')) {
    // show a small bottom toast: "Tap Share → Add to Home Screen for the app experience"
    localStorage.setItem('pwa-ios-hint-shown', '1');
}
```

## Phase 2 — Capacitor Native Wrapper (App Store / Play Store)

Use this path when PWA limitations become a problem (background audio on iOS,
push notifications, better mic access). Capacitor wraps the web app in a real
native shell.

### Setup

```bash
cd iskra_mobile
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
npx cap init Iskra foo.iskra.app --web-dir ../iskra_webclient
```

`capacitor.config.json`:
```json
{
  "appId": "foo.iskra.app",
  "appName": "Iskra",
  "webDir": "../iskra_webclient",
  "server": {
    "url": "https://app.iskra.foo",
    "cleartext": false
  }
}
```

Using `server.url` means the app always loads the latest web version live — no
need to rebuild the native wrapper on every update. Only rebuild the native
wrapper when touching native plugins.

### Generate Native Projects

```bash
npx cap add android
npx cap add ios        # requires macOS + Xcode
npx cap sync
```

### Android Build

```bash
npx cap open android   # opens Android Studio
# Build → Generate Signed Bundle/APK for Play Store
```

Play Store: create app listing at play.google.com/console, upload `.aab` bundle.

### iOS Build

```bash
npx cap open ios       # opens Xcode (macOS only)
# Product → Archive → Distribute to App Store
```

Requires: Apple Developer account ($99/yr), Xcode on macOS.

## iOS-Specific Notes

| Issue | Fix |
|---|---|
| Background audio muting | Capacitor native wrapper with AVAudioSession config — set `AVAudioSessionCategoryPlayAndRecord` with `allowBluetooth` option in `AppDelegate.swift` |
| WebRTC mic on iOS 14 | Works in WKWebView (Capacitor uses WKWebView). getUserMedia works fine. |
| Push notifications | Add `@capacitor/push-notifications` plugin; use FCM (Android) and APNs (iOS) |
| Deeplinks (`iskra://`) | Register URL scheme in `Info.plist` / `AndroidManifest.xml`; Capacitor has App plugin for this |

---

## Push Notifications (Capacitor Only)

```bash
npm install @capacitor/push-notifications
npx cap sync
```

Replace the `IS_WEB` `new Notification()` calls with Capacitor `PushNotifications.createChannel`
+ local notification trigger for in-app events. Use FCM for Android, APNs for iOS.

For the server side: the Iskra server would need to send a push payload to a relay
endpoint (FCM/APNs). This is a non-trivial backend addition — defer until after the
Capacitor wrapper is shipped and validated.

## Deployment Flow (after both phases)

```
iskra_webclient/   ──▶  Cloudflare Pages (app.iskra.foo)
                             ▲
                    PWA (Add to Home Screen)
                             ▲
                    iskra_mobile/ (Capacitor)
                      ├── Android → Play Store
                      └── iOS → App Store
```

The Cloudflare Pages deploy is the single source of truth. The native apps
just load that URL in a WebView shell. Update the web app → all platforms updated
automatically, no store submission needed.

## Implementation Order

### PWA Phase
1. Generate icons from Iskra logo
2. Write `manifest.json`
3. Write `service-worker.js`
4. Add `<link rel="manifest">` + apple meta tags to `iskra_webclient/index.html`
5. Register service worker in boot sequence
6. Add iOS "Add to Home Screen" hint toast
7. Test: Chrome DevTools → Application → Manifest; Lighthouse PWA audit
8. Deploy to Cloudflare Pages

### Capacitor Phase (later)
1. `cd iskra_mobile && npm install`
2. `npx cap init` + config
3. `npx cap add android` → test on Android emulator
4. `npx cap add ios` → test on iOS simulator (needs macOS)
5. Configure background audio for iOS (`AVAudioSession`)
6. Generate signed builds for both stores
7. Submit to Play Store (faster review ~1-3 days)
8. Submit to App Store (review ~1-7 days)
